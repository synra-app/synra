# 可靠性：重连、断点与宿主策略

## 传输重连 ≠ 文件会话自动续传

- **连接断开再建立**：底层可能是新的 TCP / 会话上下文，对端**未必**仍保留未完成组装的缓冲区。
- **结论**：不能假定「链路与上次相同即可接着发下一块」；**续传必须在会话层显式设计**。

## 两层 ACK（勿混淆）

| 层级            | 机制                                                                                                                                                           | 含义                                                                                 |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **传输 / 帧**   | 如 **`MESSAGE_ACK_AUTO`**、`device.tcp.ack`（见 [message-envelope-and-validation.md](../cross-platform-communication-map/message-envelope-and-validation.md)） | 表示「这一帧已被对端栈接收」，**不**表示「文件会话已处理到哪一块」或「磁盘已写入」。 |
| **会话 / 文件** | 可选 **`file.transfer.progress`**（payload 内 **`receivedThroughChunkIndex`** 等），或产品定义的块 ACK / checkpoint                                            | 表示**传输会话**层面的进度或确认；用于断点续传、弱网补块策略。                       |

实现会话级进度时，应使用 **`file.transfer.*`** 的 **`payload`** 表达，**不得**把「已收到第 N 块」塞进信封扩展字段。

## 会话层建议能力

| 能力                  | 说明                                                                                                                    |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **稳定 `transferId`** | 标识一次传输；重试时携带同一 id，避免与别会话混淆。                                                                     |
| **进度确认**          | 按块 **ACK**、或聚合 checkpoint（例如已收最高序号），发送端只补未确认块；对应 **`file.transfer.progress`** 或等价约定。 |
| **接收端状态**        | 未完成时可内存组装或落临时文件；若仅内存，断连后往往只能**全量重传**或从**持久化 checkpoint**恢复。                     |
| **超时与取消**        | `file.transfer.abort`、会话 TTL，防止半包长期占用资源。                                                                 |
| **轮次隔离**          | 使用 **`syncSessionId`** 或与 `transferId` 绑定的世代号，防止旧块混入新轮。                                             |

## 产品预期

- **弱网**：优先保证 **可恢复 + 可解释错误**；必要时 UI 提示「从头重传」。
- **宿主策略**：单用户并发传输数、单文件大小、是否允许后台传输，在宿主或 SDK 层统一配置。
